# Abartılı Kahve Demleme Ritüeli

## Bu Proje Nedir?

Bu, sadece bir kahve demleme kodu değil. Bu, insanlığın kahveyle olan ilişkisinin derin, felsefi ve tamamen saçma bir analizidir. Her demleme, bir varoluş krizidir. Su ısınırken düşünülmesi gereken şeyler vardır: Neden buradayız? Neden kahve içiyoruz? Neden kayyum onayı olmadan hiçbir şey yapamıyoruz?

## Özellikler

- Su sıcaklığını abartılı bir şekilde hesaplar.
- Demleme süresini rastgele uzatır çünkü acele etmek modern çağın hastalığıdır.
- Her fincan için felsefi bir alıntı üretir.
- Kayyum vergisi ekler (her zaman %13, çünkü neden olmasın).

## Kurulum

```bash
pip install -r requirements.txt  # aslında gereksinim yok ama ciddi görünsün diye
python demle.py
```

## Uyarı

Bu kodu çalıştırmadan önce bir fincan gerçek kahve için. Yoksa kod size kızar.
